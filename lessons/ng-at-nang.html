GRAMATIKA • ARALIN 01

Wastong Paggamit ng Ng at Nang

Alamin ang pagkakaiba ng dalawang salitang madalas mapagpalit sa pagsulat at pagpapahayag.

🎯 Layunin ng Aralin

Pagkatapos ng araling ito, inaasahang magagawa mong:

  • Maipaliwanag ang pagkakaiba ng ng at nang.
  • Matukoy ang wastong gamit ng mga ito sa pangungusap.
  • Makabuo ng mga pangungusap na gumagamit ng ng at nang.

1. Ano ang “Ng”?

Ginagamit ang ng upang magpakita ng pagmamay-ari, tumukoy sa layon ng pandiwa, o maglarawan ng dami at bahagi.

Mga halimbawa

• Bumili ako ng bagong kuwaderno.

• Ang aklat ng mag-aaral ay nasa mesa.

• Kumain siya ng dalawang mansanas.

2. Ano ang “Nang”?

Ginagamit ang nang upang maglarawan kung paano, kailan, o gaano ginawa ang isang kilos. Ginagamit din ito sa ilang pag-uulit ng pandiwa at bilang katumbas ng “noong” sa ilang pangungusap.

Mga halimbawa

• Tumakbo siya nang mabilis.

• Umalis sila nang maaga.

• Nang dumating ang guro, tumahimik ang klase.

• Takbo nang takbo ang bata.

3. Paghahambing

Ng: Nagdala siya ng pagkain.

Nang: Naglakad siya nang dahan-dahan.

Tandaan: Karaniwang ginagamit ang “ng” para sa layon o pagmamay-ari, samantalang ginagamit ang “nang” para ilarawan ang paraan, panahon, o antas ng kilos.
